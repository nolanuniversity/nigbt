🚀 GitHub Pages Deployment Guide

Step-by-step instructions to deploy the Nolan Institute website using GitHub Pages.

1 Prerequisites

  • A GitHub account
  • Git installed on your computer (download here)
  • The Nolan Institute website files (index.html, assets folder, etc.)

2 Create a GitHub Repository

  1. Log in to GitHub and click the + icon → New repository
  2. Repository name: nolaninstitute
  3. Description: "Nolan Institute of Global Business & Technology website"
  4. Set to Public (or Private with GitHub Pages paid plan)
  5. Click Create repository

3 Upload Files via Command Line

# Clone the repository
git clone https://github.com/yourusername/nolaninstitute.git

# Navigate into the folder
cd nolaninstitute

# Copy all your website files into this folder

# Add all files
git add .

# Commit the files
git commit -m "Initial commit: Nolan Institute website"

# Push to GitHub
git push origin main

4 Upload Files via GitHub Website (Alternative)

  1. In your repository, click Add file → Upload files
  2. Drag and drop all your website files and folders
  3. Add a commit message like "Initial website upload"
  4. Click Commit changes

5 Enable GitHub Pages

  1. Go to your repository on GitHub
  2. Click Settings (tab)
  3. In the left sidebar, click Pages
  4. Under "Branch", select main and /(root)
  5. Click Save
⏳ Wait a moment: Your site will be published at https://yourusername.github.io/nolaninstitute within 1-2 minutes.

6 Custom Domain (Optional)

To use a custom domain like nolaninstitute.org or institute.nolanuniversity.org:

  1. In your repository, create a file named CNAME (no extension)
  2. Inside the file, write your custom domain: nolaninstitute.org
  3. In your domain registrar's DNS settings, add a CNAME record pointing to yourusername.github.io
  4. Wait for DNS propagation (can take up to 48 hours)

7 Troubleshooting

  • 404 Error: Make sure your main file is named index.html (not Index.html or other)
  • Images not loading: Check that image paths are correct (use relative paths like assets/images/)
  • CSS not applying: Verify the link to style.css is correct
  • Site not updating: Clear your browser cache or wait a few minutes
