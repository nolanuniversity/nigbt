📊 Google Analytics Setup Guide

Follow these steps to add website tracking to the Nolan Institute website.

1 Create a Google Analytics Account

Go to analytics.google.com and sign in with your Google account. Click "Start measuring" and create a new property.

  • Account name: Nolan University
  • Property name: Nolan Institute Website
  • Reporting time zone: Your local time zone
  • Currency: USD

2 Get Your Tracking Code

After creating the property, go to Admin → Data Streams → Web. Enter your website URL (e.g., https://nolanuniversity.github.io/nolaninstitute).

You will receive a Measurement ID (format: G-XXXXXXXXXX) and a JavaScript tracking code snippet.

3 Add the Code to Your Website

Copy the tracking code and paste it into the <head> section of every HTML page, just before the closing </head> tag.

<!-- Google tag (gtag.js) -->
<script async src="https://www.googletagmanager.com/gtag/js?id=G-XXXXXXXXXX"></script>
<script>
  window.dataLayer = window.dataLayer || [];
  function gtag(){dataLayer.push(arguments);}
  gtag('js', new Date());
  gtag('config', 'G-XXXXXXXXXX');
</script>

Replace G-XXXXXXXXXX with your actual Measurement ID.

4 Event Tracking (Optional)

Track button clicks, form submissions, and other interactions on Nolan Institute pages:

// Track "Apply Now" button click
gtag('event', 'button_click', {
  'event_category': 'engagement',
  'event_label': 'apply_now'
});

// Track application form submission
gtag('event', 'form_submit', {
  'event_category': 'conversion',
  'event_label': 'central_application'
});

// Track programme enquiry
gtag('event', 'programme_enquiry', {
  'event_category': 'engagement',
  'event_label': 'programme_interest'
});

Add these to your main.js file for specific elements.

5 Verify Installation

Use the Google Analytics Debugger Chrome extension or check Realtime reports in your GA dashboard to confirm data is being received.

📈 Key Metrics to Monitor

  • Page Views: Which programmes and schools are most viewed?
  • Bounce Rate: Are visitors engaging with programme content?
  • Conversion Rate: How many visitors complete the Central Application?
  • Traffic Sources: Where are prospective learners coming from?
  • User Demographics: Location, device and behaviour across African and international applicants
